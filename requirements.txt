========================
Additional Requirements
========================

1. Python 3.10 or later

2. Install the required Python packages:

   pip install -r requirements.txt

3. To use the email feature, you must configure a Gmail App Password.

Steps:
- Enable 2-Step Verification on your Google Account.
- Go to Google Account → Security → App Passwords.
- Create a new App Password for "Mail".
- Use your Gmail address and the generated 16-character App Password when running the application.

Important:
Do NOT use your normal Gmail account password. Gmail App Passwords are required for email authentication.
